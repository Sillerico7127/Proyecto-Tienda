# Proyecto Tienda
Tecnologias en Internet
El presente proyecto consiste en el diseño, desarrollo e implementación de un sitio web corporativo y
catálogo en línea para la Tienda de Deportivos en La Paz, Bolivia. El objetivo principal es aplicar los
conocimientos de la materia de Tecnologías de Internet para digitalizar un negocio local, permitiendo la
visualización de productos (poleras, chompas y pantalones)
