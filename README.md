# Proyecto Tienda

## Tecnologias en Internet

El presente proyecto consiste en el diseño, desarrollo e implementación de un sitio web corporativo y catálogo en línea para una Tienda de Ropa Deportiva en La Paz, Bolivia. El objetivo principal es aplicar los conocimientos de la materia de Tecnologias de Internet para digitalizar este negocio local, permitiendo la visualización y comercio de sus productos de forma 100% digital.

El sitio web contará con un catálogo virtual interactivo donde los clientes podrán ver fotos, tallas y precios de todas las poleras, chompas y pantalones disponibles. Además, incluirá un sistema de ventas en línea con un carrito de compras y un módulo de contacto directo para coordinar los pagos y los envíos dentro de la ciudad de La Paz, permitiendo que el negocio atienda a sus usuarios las 24 horas del día.
